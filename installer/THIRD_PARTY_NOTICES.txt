FIRST-RUN DOWNLOADED AI MODEL GROUPS (NOT BUNDLED IN INSTALLER)
--------------------------------------------------------------------------------

By default ("Option 1 — Slim Installer + First-Run Model Downloader"), AI model
weights are NOT bundled inside SecondBrain-Setup-x64.exe. Instead, on first
launch (or via local folder import), the desktop setup assistant downloads the
following 6 model groups from their upstream repositories into
`%LOCALAPPDATA%\SecondBrain\data\models`:

1. `BAAI/bge-m3` — Dense & learned sparse multilingual embeddings
   License: MIT License
   Origin:  https://huggingface.co/BAAI/bge-m3

2. `convaiinnovations/laya-multilingual` — Domain & modality classifier
   Origin:  https://huggingface.co/convaiinnovations/laya-multilingual
   Note:    Subject to the upstream model repository license and terms.

3. `Qdrant/bm25` — FastEmbed BM25 sparse lexical model & IDF tables
   License: Apache License 2.0 (via FastEmbed / Qdrant)
   Origin:  https://huggingface.co/Qdrant/bm25

4. `ms-marco-MultiBERT-L-12` — FlashRank multilingual cross-encoder reranker
   Origin:  Downloaded via FlashRank from upstream model storage; subject to
            upstream model card / HuggingFace terms.

5. RapidOCR v3 ONNX Engine — CPU ONNX detection/classification/recognition models
   License: Apache License 2.0
   Origin:  https://github.com/RapidAI/RapidOCR

6. Docling v2 Layout & TableFormer (`docling-project/docling-models`)
   License: MIT License
   Origin:  https://huggingface.co/docling-project/docling-models
